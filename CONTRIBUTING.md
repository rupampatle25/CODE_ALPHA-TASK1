# Contributing to BhashaSetu

Thank you for your interest in contributing to BhashaSetu!

## Development Workflow

1. **Fork or branch:** Create a feature branch (`git checkout -b feature/amazing-feature`).
2. **Setup environment:** Install dependencies with `npm install` and ensure tests pass (`npm test`).
3. **Coding conventions:**
   - Write clean, well-commented TypeScript code.
   - Use Tailwind utility classes for consistent styling.
   - Use Zod schemas for validating any new API endpoint inputs.
4. **Verification:**
   - Run type checking and production build: `npm run build`
   - Run the automated test suite: `npm test`
5. **Commit:** Keep commit messages descriptive and clear.
